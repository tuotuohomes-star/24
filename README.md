# Material Price Merge

> 面向非技术用户的离线 Excel 物料价格合并工具

[![License: MIT](https://img.shields.io/badge/License-MIT-0f766e.svg)](LICENSE)
![Privacy: Local only](https://img.shields.io/badge/Privacy-Local%20only-0f766e)
![Platform: macOS & Windows](https://img.shields.io/badge/Platform-macOS%20%7C%20Windows-475569)

无需安装、打开网页即可使用。工具以价格表为基础，按物料编码匹配物料主数据，补充业务状态并导出新的 `.xlsx` 文件。

所有数据都在浏览器本地处理，不会上传到服务器。它适合需要处理内部价格、库存或物料信息，又不希望把源文件交给在线服务的个人和团队。

![配套产品价格查询界面](assets/product-price-finder.png)

> 上图是配套产品价格查询界面的实际运行效果，用于展示合并数据的下游使用场景。本仓库只开源离线合并工具，不包含真实价格数据或线上数据库。

## 主要功能

- 按“物料编码”匹配两份 Excel
- 同时核对物料名称和规格
- 提示缺失编码、重复编码和字段冲突
- 支持较大的 `.xlsx` 文件分段读取
- 在导出前预览记录数、业务状态和异常数量
- 支持 macOS 和 Windows，打开 HTML 文件即可使用

## 为什么做这个项目

很多业务团队需要把价格表和物料主数据反复合并，但传统做法通常依赖复杂公式、人工复制或把内部文件上传到在线工具。本项目希望提供一个简单、透明、可复用的本地方案：业务人员不需要编程，也能完成匹配、校验和导出。

## 快速开始

1. 下载本仓库，或在 GitHub 页面选择 **Code → Download ZIP**。
2. 解压后双击 `上市产品价格合并工具.html`。
3. 选择价格表和物料主数据表。
4. 检查结果与异常提示。
5. 点击“导出 Excel”。

也可以双击 `打开工具.command`（macOS）或 `打开工具.bat`（Windows）。

## Excel 字段要求

价格表需要包含：

`物料编码`、`物料名称`、`规格`、`单价`

物料主数据需要包含：

`物料编码`、`物料名称`、`规格`、`物料业务状态`

列的位置可以变化，程序会根据表头文字识别。

## 合并规则

- 保留价格表中的全部记录和原有顺序。
- 优先以物料编码作为匹配键。
- 名称或规格不一致时仍按编码匹配，同时显示异常提示。
- 找不到编码时保留原价格记录，并把状态标记为“未匹配”。
- 导出字段为：物料编码、物料名称、规格、单价、物料业务状态。

## 适用场景

- 为产品查询页面准备结构统一的数据
- 定期把价格表与 ERP/物料主数据对齐
- 检查缺失编码、重复编码或名称规格冲突
- 在不能上传内部数据的环境中完成 Excel 合并

## 隐私与安全

工具是静态网页，不需要服务器。导入、匹配、预览和导出均在当前浏览器中完成。仓库不包含任何真实价格表、物料主数据、账号、密码或 API 密钥。

建议只在可信设备上处理敏感 Excel，并在使用后关闭页面。

## 浏览器支持

推荐最新版 Chrome、Microsoft Edge 或 Safari。大文件处理期间请保持页面打开。
